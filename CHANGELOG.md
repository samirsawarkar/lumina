# Changelog

## 0.1.0 — 2026-11-11

First public release.

- **Privacy check-up:** finds passports, payment cards, passwords and ID documents; reports counts and kinds only.
- **Safe Send:** redacted copies of library photos or any image file, verified by re-reading the copy; presets for hotel, airline and everything.
- **Leak Guard:** blocks outbound Hermes tool calls that carry a raw image of an ID document.
- **Photo assistant:** search by person, place, scene, album or text in the image; expiry dates; albums; "on this day"; memory videos; export to messaging.
- **Hermes Desktop UI:** inline photo grid, side pane, Safe Send card with a before/after slider.
- Handles real document layouts: all-caps licence titles, card numbers read in groups of four, `dd-mm-yyyy` dates, two-column passports.
