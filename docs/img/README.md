# Documentation Image Assets

Screenshots and media assets to capture for Lumina documentation:

- `hero.png`: Hermes Desktop chat window showing Lumina responding to a natural query with an inline thumbnail grid and the Lumina side pane open.
- `grid-2025.png`: Inline `::lumina-photos` chat directive displaying a responsive photo tile grid titled "Photos from 2025" with dates and the "+N more" button.
- `pane.png`: Lumina side pane showing Apple Photos library status counts and a scrollable grid of medium-resolution thumbnail previews.
- `phone-telegram.png`: Mobile chat screen (Telegram/WhatsApp) receiving an exported high-resolution photo sent as a Hermes MEDIA attachment.
- `demo.gif`: Short screen recording showing a photo search, inline thumbnail grid rendering, clicking a photo to reveal in Apple Photos, and opening the side pane.
